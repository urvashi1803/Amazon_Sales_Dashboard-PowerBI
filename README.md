# Amazon Sales Dashboard - Power BI

### Project Overview
Created an interactive dashboard for Amazon sales data to track revenue and performance.

### Data Cleaning in Power Query
- Removed null values and duplicates
- Fixed date format and currency column
- Removed unnecessary columns

### Dashboard Includes
- Total Sales, Profit
- Sales by Category, State, Month
- Top 5 products

### Tools Used: Power BI, Power Query, Excel

### Files
- Amazon Sale Report.csv (Original)
- Amazon sales dashboard FINAL.pbix (Final file with cleaned data)
